# MyPlanner

Native Android productivity planner — offline-first, built with Kotlin, Jetpack Compose, and Material 3.

## Phase 2 — Design system & UI foundation

Complete reusable visual design system for a calm, premium productivity experience. Feature screens (Hello, tasks, reminders, notes) are **not** implemented yet.

### What’s included

- **Theme**: Custom Material 3 light & dark ColorSchemes (indigo primary `#4F46E5` + teal accent `#14B8A6`), surface containers, status colors
- **Typography**: Readable hierarchy (display → label) with semibold headings and regular body
- **Spacing & shapes**: Consistent scale; 16–20dp cards; pills only for chips
- **Motion**: Short ease-out tokens for future transitions (no bounce/spin)
- **Gradients**: Brand indigo→teal reserved for hero moments only
- **Components**:
  - Buttons: primary, secondary, tonal, text, icon, FAB
  - Cards: standard, surface, tinted, hero
  - Text fields, filter/input chips, list items, dividers
  - PageHeader, SectionHeader
  - Empty, loading, and error states
- **Gallery**: Internal `DesignSystemScreen` (dev validation, not product navigation)

### Architecture preserved from Phase 1

Room, DataStore, Navigation Compose foundation, offline-first package structure.

### Build & run

1. Open the repo root in Android Studio (Ladybug+).
2. Sync Gradle (wrapper JAR is generated by Studio if missing).
3. Run on device/emulator — the design system gallery is the start destination.

### Package structure (UI)

```
ui/
├── theme/          Color, Type, Shape, Spacing, Theme, Motion, Gradient
├── components/     Buttons, cards, fields, chips, list, states, headers
├── foundation/     DesignSystemScreen (dev gallery)
└── navigation/     NavGraph
```

### Design principles

- Calm, spacious, professional — not generic Material defaults
- Restrained color; status colors only when semantic
- Subtle tonal elevation over heavy shadows
- Gradients sparingly (hero only)
- Accessible contrast, 48dp touch targets, content descriptions
- Responsive to phone and tablet widths
